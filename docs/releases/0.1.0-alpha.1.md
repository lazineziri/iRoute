# iRoute 0.1.0-alpha.1

- Release date: 2026-08-01
- Channel: alpha prerelease
- Public API: v1

This is the first public open-source alpha of the task-aware iRoute runtime. It
completes workstreams W01-W18 with a credential-free deterministic quick start,
durable asynchronous execution, provider resilience, and production-shaped
PostgreSQL/Kubernetes references.

## Maturity and support

- This release is experimental. Breaking changes are expected before `1.0`.
- There is no production SLA and no security-response or remediation SLA.
- Reference connectors demonstrate normalized boundaries; they are not
  production integrations.
- Checked provider quality, latency, token, and cost figures are deterministic
  regression inputs, not validated production measurements or billing data.
- Self-hosters are responsible for authentication, TLS, secrets, backups,
  network controls, provider configuration, and operational monitoring.

## Highlights

- Resolve trusted project state and deterministic work before invoking a model.
- Compile bounded, provenance-bearing context instead of forwarding full history.
- Route against measured quality, cost, latency, token, capability, and policy
  constraints with explainable decisions.
- Persist workflows, approvals, external-action reservations, artifacts, memory,
  dependency edges, lifecycle archives, events, and observability.
- Integrate providers only through generic model-gateway and normalized
  capability boundaries.
- Persist execution before processing, claim work with fenced leases, recover
  from worker interruption, and replay ordered events over reconnectable SSE.
- Route across registered generic gateway deployments with classified failures,
  distributed circuit state, bounded half-open probes, and deterministic fallback.
- Operate with schema-aware readiness, explicit migrations, non-root containers,
  and horizontally scaled API replicas.
- Use six protocol-only SDKs and the `iroute` CLI against the same v1 contract.

## Install

Follow [the clean installation guide](../installation.md). The smallest path is:

```bash
docker compose --file deploy/compose.sqlite.yaml up --build --wait
curl --fail http://localhost:8080/health/ready
```

## Compatibility and security

This is an alpha prerelease. The published v1 wire contract remains additive as
defined in [the compatibility promise](../compatibility.md), while runtime,
configuration, and source extension points may break before `1.0`. Only the
latest tagged prerelease receives best-effort security fixes without a response
or remediation SLA. Report vulnerabilities through a private repository
security advisory as described in [SECURITY.md](../../SECURITY.md).

## Known limits

- Distributed tenant concurrency, request-rate, queue-depth, token, and cost
  quotas are not implemented; unrestricted multi-tenant workloads are unsafe.
- Sustained load, soak, database failover, and production provider behavior have
  not been validated.
- Reference connectors and the deterministic model gateway are test adapters,
  not production integrations.
- Provider quality, latency, token, and cost figures are not production evidence.
- The lifecycle worker must remain one replica per database until distributed
  lifecycle leasing exists.
- `DevelopmentHeaders` fails startup outside the Development environment. Real
  deployments must configure JWT.
- Authentication, TLS, PostgreSQL backups, ingress, secrets, network controls,
  real gateway deployments, and operational monitoring remain self-hoster
  responsibilities.
- SDK registry publication is not implied by this source release.

## Release progression

- `0.1.0-alpha.1`: public open-source alpha for evaluation and controlled pilots.
- W19 plus security, provider, and load validation: private beta.
- Real operational evidence and completed runbooks: production candidate.
- Sustained successful pilots: `1.0`.

## Upgrade and rollback

This is the first tagged prerelease. Existing source deployments should back up
PostgreSQL, run the release migration image `status` and `up` commands, then roll
API replicas and finally replace the single worker. Prefer application rollback
while retaining the additive schema. Follow [operations.md](../operations.md)
before any confirmed schema downgrade.

## Integrity

The GitHub release includes `release-manifest.json` and `SHA256SUMS`. Verify every
download before use. Container images built by downstream operators must be
pinned by immutable version and, for production, digest.
