# iRoute.Sdk

Thin .NET client for the iRoute v1 HTTP and SSE protocol. Configure a base URI,
tenant, actor, and optional permissions, then use `IRouteClient` for executions,
streaming, cancellation, approvals, artifacts, health, and observability.

Routing, planning, model/provider choice, memory, validation, and retry policy
remain server-side. Apache-2.0 licensed.
